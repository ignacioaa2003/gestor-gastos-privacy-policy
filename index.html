Política de Privacidad

Gestor de Gastos es una aplicación offline de gestión financiera personal.

Recopilación de datos

Esta aplicación no recopila, almacena ni comparte datos personales de los usuarios.

Conexión a Internet

La aplicación funciona completamente de forma local y no requiere conexión a Internet.

Archivos y almacenamiento

La aplicación puede acceder al almacenamiento del dispositivo únicamente para importar o exportar copias de seguridad de la base de datos, siempre mediante acciones iniciadas por el usuario.

Terceros

La aplicación no utiliza servicios de terceros, publicidad ni herramientas de seguimiento.

Contacto

Si tienes preguntas sobre esta política de privacidad, puedes contactar con el desarrollador.
